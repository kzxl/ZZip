# ZZip Project Directives
- **Architecture:** Keep `Ztar.Core` completely independent of WinForms / UI dependencies for cross-platform extraction.
- **Append SFX Protocol:** Maintain binary append-mode SFX format; recipients must be able to execute self-extractors without installing .NET SDK or runtime.
- **Compression Safety:** Always verify CRC32 and authenticated AES-256-GCM integrity tags during packing and extraction.
- **Process Cancellation:** Handle `Ctrl-C` gracefully in CLI mode (first press for graceful stop, second for forced termination).
